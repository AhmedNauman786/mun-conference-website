# Model United Nations Website

A fully interactive, modern single-page website designed for Model United Nations (MUN) conferences and organizations.

## Features

- **Extremely modern dark theme** with gradient accents and glassmorphism
- **Smooth animations** everywhere: scroll reveals, hover effects, floating elements, particle background
- **Interactive elements**:
  - Animated particle network background that reacts to mouse movement
  - Counter animations for statistics
  - Clickable committee cards with detailed modals
  - Fully functional registration form with validation and success state
  - Smooth scroll navigation with active link highlighting
  - Mobile-responsive hamburger menu
  - Back-to-top button
  - Toast notifications
- **Sections**: Hero, About, Committees, Experience, Events, Testimonials, Registration, Footer
- **Responsive** design for desktop, tablet, and mobile

## How to Use

1. Open `index.html` in any modern web browser
2. No build step required — pure HTML, CSS, and JavaScript
3. Requires internet connection only for Google Fonts and Font Awesome icons (CDN)

## Customization

- Colors and theme variables are in `css/styles.css` under `:root`
- Content can be edited directly in `index.html`
- Committee details and form behavior are in `js/script.js`

## Browser Support

Works best in latest Chrome, Firefox, Safari, and Edge.
